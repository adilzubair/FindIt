# FindIt identity

The original FindIt desktop icon was generated with the built-in imagegen tool, then converted to a Windows multi-resolution ICO without changing its design. The original alpha channel is preserved.

- `FindIt.png`: 1024px transparent source for the in-app identity.
- `FindIt.ico`: 16, 20, 24, 32, 48, 64, 128, and 256px Windows resources.
- Identity: cobalt archive folder, two pale index cards, and an ivory magnifying glass. Large simple shapes retain legibility in the taskbar.

Generation prompt:

Use case: logo-brand. Asset type: a production Windows desktop application icon for FindIt, a beautiful offline photo/video/document search library. Create one isolated square icon, centered, with genuine transparency outside the icon silhouette. Design a distinctive premium Fluent-style icon: a softly rounded cobalt-blue archive folder with two slightly offset light-blue index cards emerging from it, and a bold ivory magnifying-glass lens integrated into the lower right of the folder. The folder, cards and lens form one compact legible silhouette, not scattered objects. Refined restrained depth, subtle bevels, soft directional highlights, crisp edges, rich blue #3868EE / periwinkle #83A8FF with an ivory search ring. Front-facing with just a very slight dimensional tilt, professionally art-directed desktop software identity. Fill about 84 percent of the square canvas and keep generous transparent outer clearance for Windows taskbar use. Strong broad simple shapes that remain readable at 16, 24, 32 and 48 pixels; no fine lines, no tiny text, no letters, no wordmark, no busy texture. No platform frame or screenshot, no desktop, no checkerboard, no background glow, no cast shadow outside silhouette, no watermark. A single finished icon, not a contact sheet.
